# Architecture

`cli.py` builds the persisted `RunContract`. It auto-approves only safe Python compilation and stores ambiguous package-marker commands as non-executing verification proposals; approved contracts probe executables and negotiate Codex flags before workers start. `engine.py` owns transitions, budgets, fingerprint refusal, Writer scheduling, and completion commits. `evidence.py` owns evidence/content identity, `review.py` owns final-review and resumed-attempt handling, `pack.py` owns bounded read-only fan-out and synthesis, and `recovery.py` reconstructs durable state. `adapter.py` launches Codex with argv plus stdin. `agentflow.py` invokes an optional installed AgentFlow CLI without importing it. `process.py` streams/redacts artifacts and owns cancellation. `store.py` supplies atomic JSON, fsynced JSONL, parent-directory durability, and the canonical-workspace lock. `verification.py` owns the immutable Git baseline, machine checks, and baseline-relative path gates; `scoring.py` ranks evidence and `structured.py` validates worker JSON.

Each canonical workspace has one Hound execution lock. Read-only processes overlap only inside a bounded Pack; independent workspaces can run concurrently. Historical traces stay in redacted artifacts; prompts receive capped context, baseline-relative diffs, Pack rankings, and artifact references. Resume charges the persisted in-flight interval to the wall budget and validates unfinished launch identity before mutation. A live or unverifiable orphan produces retryable exit `4` with no state/summary change. Dead launches become `interrupted`. Only durable Writer intent plus completed `result.json` or `final.txt` reconstructs a Writer action; partial streams remain evidence. Redaction, hashing, and native AgentFlow completed-node import run asynchronously, with recovered run state committed only after the batch succeeds. The bounded recovery digest is supplied only to the immediately following Writer round.

Hound exposes no DAG DSL and adds no AgentFlow runtime dependency. AgentFlow owns only the temporary read-only parallel pipeline; Hound remains the durable loop, single-Writer owner, completion authority, and artifact index. Qualified automatic Packs prefer AgentFlow; live per-node quality culling remains a direct-fallback feature. Child executables are resolved before launch without Windows' implicit current-directory search. Production Codex sessions are ephemeral and use a process-private `CODEX_HOME` with copied authentication and a snapshot of non-system user skills, while global config and `.system` skills are neither loaded nor mutated. Normal exit deletes that home; later launches reap only marked Temp-directories whose owner PID is dead. Test prefixes receive neither real authentication nor user skills.

On Windows, Hound pins the native `elevated` Codex sandbox, disables approval escalation, starts children without console windows, and suppresses inherited process-error dialogs. Cancellation is one fail-closed path: validate direct parentage, kernel creation identity, image path, ancestry, and every subtree executable; then invoke only the System32 `taskkill` binary for that exact PID tree.

The 500-line module target remains a soft maintainability guide. `engine.py` and `process.py` are deliberate exceptions; release measurements must report them honestly rather than treating the target as an invariant.
