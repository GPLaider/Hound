# Adaptive Pack

Pack triggers when explicitly on, requested with distinct missions, or justified by a blocked Writer, repeated identical machine/Verifier failure, or idle evidence. It is skipped for clear solo work and insufficient budgets. After repeated final-review failure, an evidence-empty Pack ends the run `BLOCKED` instead of enabling another empty review cycle.

`backend = "auto"` prefers AgentFlow for a qualified Pack only when native member culling is safe or unnecessary. Hound delegates a small AgentFlow JSON pipeline whenever at least two distinct non-empty missions and two workers fit concurrency and remaining budget, the enabled CLI is available, and the platform can safely cull the excess over `survivors`. Windows therefore routes cullable Packs to Hound's guarded direct supervisor while AgentFlow remains eligible when every Scout is retained. Missions may come from the Writer or Hound's bounded blocked/idle/repeated-failure defaults. Every automatic choice and its culling requirement are persisted as `pack_backend_selected`.

When qualified, AgentFlow supplies bounded parallel execution and its own durable node artifacts. Hound emits one read-only Scout fanout group. On platforms where AgentFlow member cancellation preserves Hound's process-safety contract, semantic judging, budget, and survivor headroom may add one read-only periodic controller charged to the total-worker budget. Each Scout permits one retry; the controller permits none. The first controller tick is observe-only; later ticks are separated by the maximum of `minimum_runtime_seconds`, `judge_interval_seconds`, and `cull_cooldown_seconds`. Its prompt applies `survivors`, `minimum_progress_events`, `minimum_score_gap`, and unique-evidence protection. Hound then audits the native action envelopes and applied-action log, rejecting non-cancel, multi-target, outside-fanout, reasonless, early, or survivor-floor-breaking requests. Only a matching applied cancellation is recorded as `culled`. Windows omits the controller because AgentFlow's local runner uses direct process termination rather than Hound's guarded exact PID-tree path; automatic cullable Packs use the safe direct backend instead. Hound imports and redacts the artifacts, scores completed/recovered results, retains the strongest configured evidence, and gives a byte-bounded digest to the next sole Writer. On resume, the stable Hound-worker-to-expanded-node map supports native fanout imports while old flat manifests remain readable.

Hound deliberately does not import AgentFlow as a Python dependency or expose its DAG. If AgentFlow is absent or fails before completing any Scout, `auto` falls back to Hound's direct Pack.

The direct backend keeps the live culling policy. It always waits `minimum_runtime_seconds`. Until the observation deadline, it also waits while any live Scout has fewer than `minimum_progress_events`; a genuinely stalled Scout cannot defer the Pack forever. Deterministic scoring uses concrete evidence, relevant terms/paths, hypotheses, progress events, repetition, errors, and output efficiency. After `judge_interval_seconds`, if the bottom scores remain closer than `minimum_score_gap`, concurrency and worker budget allow one read-only Judge to contribute semantic scores:

```text
final = deterministic * 0.6 + semantic * 0.4
```

Only one live Scout is culled per cooldown. The supervisor refuses to cull below `survivors` and protects a worker carrying unique path evidence when an alternative exists. Every cull writes timestamp, score, order, and reason; stdout/stderr/trace/final partials remain available to synthesis. Both backends write `pack-ranking.json` with scores, statuses, retention, and survivor IDs. `synthesis.json` carries the baseline-relative diff, compact Scout evidence, cull reasons, deduplicated hypotheses, and recommended next actions; only a bounded digest enters later prompts.

AgentFlow performs selective culling through its own expanded fanout node IDs. Hound never discovers or kills an inner PID, never emits console-control events, and never intentionally requests a rerun or whole-run cancellation for a member cull. Any unexpected controller action fails Hound's audit instead of becoming accepted evidence. Hound's outer timeout is shorter than Scout node timeouts and can terminate only the guarded direct AgentFlow PID tree with system `taskkill.exe /PID <pid> /T /F`; that path is reserved for Pack timeout or user/run shutdown. Completed and confirmed controller-cancelled nodes are recovered from persisted native run and event data; other unfinished nodes become `interrupted`.
